# `tascpy`

タスク計測データ処理用のPythonライブラリ

## インストール

```bash
pip install tascpy
```

Plotly による対話的な描画（`iplot`）も使う場合:

```bash
pip install "tascpy[plotly]"
```

開発版をソースからインストールする場合:

```bash
git clone https://github.com/toruinaba/tascpy.git
cd tascpy
pip install -e .
```
